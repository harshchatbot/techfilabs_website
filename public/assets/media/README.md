# Why TechFi Labs Media Assets

This folder stores the local media files used by the `Why TechFi Labs` media panel on the homepage.

## Required filenames

1. `why-ai-automation.mp4`
2. `why-integrations.mp4`
3. `why-salesforce.jpg`
4. `why-delivery.jpg`
5. `why-security.jpg`
6. `why-support.jpg`

## Acceptable alternatives

- For image files, `.webp` can be used instead of `.jpg`.
- For video files, use optimized `.mp4` files suitable for web playback.

## Notes

- Keep media dimensions reasonably consistent for a clean panel transition.
- Prefer compressed assets for faster homepage loading.
- Avoid assets with recognizable third-party logos, trademarks, dashboards, or branded products unless you have explicit rights to use them.
- If a file is missing, the homepage will show a branded placeholder automatically.
